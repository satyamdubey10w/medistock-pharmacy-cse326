# MediStock – Pharmacy Management System

## 1. Introduction
MediStock is a web-based Pharmacy Management System developed as a B.Tech Computer Science and Engineering academic project. The main purpose of this project is to simplify pharmacy operations by managing medicines, monitoring stock, tracking expiry dates, and handling billing digitally.

## 2. Problem Statement
In many pharmacies, maintaining medicine records manually can be time-consuming and may cause billing errors, stock shortages, and difficulties tracking expired medicines. MediStock aims to reduce these problems through a simple digital platform.

## 3. Objectives
The main objectives of this project are to:
- Manage medicine inventory efficiently.
- Track medicine quantities and expiry dates.
- Simplify customer billing.
- Maintain sales records.
- Provide a user-friendly interface for pharmacy staff.

## 4. Main Features
**Medicine Management:** Users can add, update, delete, and search medicine records.

**Stock Management:** The system helps monitor available quantities and identify low-stock medicines.

**Expiry Tracking:** It helps identify expired and soon-to-expire medicines.

**Billing System:** Users can prepare customer bills and update stock after sales.

**Sales History:** Previous transactions can be recorded and reviewed.

**Login Interface:** Separate admin and staff login interfaces can be provided.

**Dashboard:** Displays useful information about inventory and pharmacy operations.

## 5. Technologies Used
- **HTML:** Creates the structure of web pages.
- **CSS:** Designs the layout, colors, and user interface.
- **JavaScript:** Implements interactive features and application logic.
- **LocalStorage:** Stores data locally in the browser.

## 6. Working
The user opens the website and logs in through the available interface. The user can manage medicine records, check stock availability, monitor expiry dates, and generate bills. When a sale is completed, the medicine quantity is updated. Data stored using LocalStorage remains available in the same browser unless it is cleared.

## 7. Future Scope
Future improvements may include database integration, secure authentication, barcode scanning, supplier management, prescription records, and advanced reports.

## 8. Conclusion
MediStock demonstrates how basic web technologies can help simplify pharmacy inventory and billing operations. It provides practical experience in web development, user interface design, and data management.
